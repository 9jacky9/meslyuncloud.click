隐私政策 (Privacy Policy)

MESL Cloud 机场高度重视并尊重所有用户的个人数据与数字隐私权利。本隐私政策明确说明我们在运营过程中对待用户数据的严苛准则。

【零日志承诺】：MESL Cloud 机场严格践行“绝对无日志记录 (No-Logs Policy)”原则。我们坚决不记录、不保存、不监控、不出售用户的任何网络活动日志！

一、 绝对不收集的数据类型

为了捍卫您的绝对隐私自由，我们的服务器架构在底层设计上彻底杜绝了对下列数据的存储与分析：

  • 不记录用户的浏览历史与目标网址：您所访问的任何网站、页面或服务地址均不留存。
  • 不记录任何传输数据与通信内容：数据流全程由端到端高强度密钥加密穿透，服务器无解密也无留存。
  • 不记录用户的真实源 IP 地址：用户连接至加速节点后，连接元数据仅在内存瞬时会话中维持，断开即灰飞烟灭。
  • 不记录 DNS 查询历史：全节点采用自建私有加密 DNS 递归解析，防止任何第三方进行流量嗅探。

二、 仅保留的必要系统元数据

为维持账户基础正常运转与计费准确性，我们仅收集最基础且匿名的账户管理信息：

  • 注册电子邮箱（用于账户登录与密码找回）。
  • 套餐订阅状态及已使用流量总计（用于流量配额统计，与具体访问行为无关）。
  • 系统并发连接计数（仅用于防止超出套餐允许的设备数量限制）。

三、 数据加密与安全措施

所有专线传输节点均采用行业顶尖的高强加密传输套件（如 AEAD 密码学协议与 ChaCha20-Poly1305 / AES-256-GCM），确保数据即便在公网跨越时也坚不可摧。

四、 隐私政策的更新

我们可能根据行业安全实践与架构演进适时更新本政策，但“零日志记录”的核心原则绝不会发生任何改变。
